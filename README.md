# Dabur-India-Budget-vs.-Actual-Variance-Analysis-Model-
 Budget vs. Actual Analysis of Dabur India featuring financial forecasting, quarterly variance analysis and key variance drivers.
# Overview
Developed a Budget vs. Actual Variance Analysis model for Dabur India to evaluate FY26 financial performance against independently prepared budget estimates. The project involves forecasting revenue, operating expenses, and profitability using historical financial data, analysing quarterly and annual variances, and identifying key factors influencing financial performance.

# Objectives
- Prepare an FY26 financial budget using FY25 historical financial data and forecasting assumptions.
- Compare budgeted and actual financial performance on a quarterly and annual basis.
- Calculate and analyse favourable and unfavourable revenue and cost variances.
- Identify key variance drivers, including sales volume, price/mix, and operating expenses.
